👋 歡迎來到 AE/EE 專案成果展示平台

本軟體 App 整合了您在晶片設計與應用工程中開發的各類工具。我們將原來的 VB6 獨立軟體及 Excel VBA 巨集的數學建模邏輯、自動化分析流程，重新以 HTML5、Vanilla CSS 以及 JavaScript 移植為網頁版互動式 Demo，充分展示您在硬體工程、數學建模與軟體自動化上的核心能力。

請點擊左側導覽列，切換不同的展示模組：

  • PMIC 參數試算區：包含 FP7126 調光曲線繪圖模擬與各類 DC-DC 元件計算。
  • 通用設計工具箱：包含精密分壓阻值選擇、電感線圈匝數、MOSFET 功率損耗分析。
  • 數據與自動化中心：虛擬演示 AE Link 資料整合流程，並可上傳 CP 數據進行良率直方圖分析。
  • 選型庫與樣品管理：FTC-FP 代號模糊查詢、全系列卡片式規格目錄、以及實驗室樣品看板。
